# Plot dual-pool logistic decomposition

Visualizes the rapid pool, slow pool, total prediction, and observed
data.

## Usage

``` r
plot_dual_pools(fit, head = NULL, treatment = NULL)
```

## Arguments

- fit:

  A dual_logistic_fit object.

- head:

  Optional bottle head identifier.

- treatment:

  Optional treatment name.

## Value

A ggplot object.
