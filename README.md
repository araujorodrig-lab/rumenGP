# rumenGP

<!-- badges: start -->

<!-- badges: end -->

**rumenGP** is an R package for processing and modeling *in vitro* rumen
gas production data generated by systems such as the ANKOM RF Gas
Production System.

The package provides a reproducible workflow for:

- Importing ANKOM RF output files
- Parsing ANKOM incubation timestamps
- Converting pressure measurements into gas production
- Validating metadata and ANKOM datasets
- Fitting multiple gas production models
- Comparing competing models
- Detecting problematic bottles
- Visualizing model fits and residuals
- Generating treatment-level summaries

## Example workflow


### Load packaged example files

The package includes a small example dataset for learning the workflow
and testing package functionality.

``` r
files <- example_data()
```

### Import ANKOM data

``` r
raw_data <- read_ankom(
```

## Quality Control Workflow

The recommended workflow is:

``` text
Import data
    ↓
Validate metadata
    ↓
Process ANKOM data
    ↓
Validate processed data
    ↓
Fit models
    ↓
Flag problematic bottles
    ↓
Visual inspection
    ↓
Document exclusions
    ↓
Refit models
    ↓
Compare models
```

Example:

``` r
gp_clean <- exclude_heads(
  gp,
  heads = c("10"),
  reason = "Sensor malfunction"
)
```
