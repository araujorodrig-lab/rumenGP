# rumenGP

<!-- badges: start -->

<!-- badges: end -->

**rumenGP** is an R package for processing and modeling *in vitro* rumen
gas production data generated by systems such as the ANKOM RF Gas
Production System.

The package currently provides tools for:

- Importing ANKOM RF data
- Parsing ANKOM incubation timestamps
- Converting pressure measurements to gas production
- Joining and validating experimental metadata
- Fitting the Zwietering-modified Gompertz model
- Calculating kinetic parameters and goodness-of-fit statistics
- Flagging potentially problematic bottles
- Plotting raw gas production curves and model fits
- Documenting bottle exclusions for reproducible analyses

## Installation

Development version:

``` r
# install.packages("devtools")

devtools::install_github(
  "YOUR_GITHUB_USERNAME/rumenGP"
)
```

Or install from a local source:

``` r
devtools::install_local(
  "path/to/rumenGP"
)
```

### Import ANKOM data

``` r
raw_data <- read_ankom(
  files$ankom
)

metadata <- read_metadata(
  files$metadata
)
```

### Validate metadata

``` r
metadata <- validate_metadata(
  metadata
)
#> Metadata validation passed.
#> Heads: 24
#> Treatment: 5
```

### Process ANKOM data

``` r
gp <- process_ankom(
  raw_data,
  metadata,
  headspace_ml = 210,
  temperature_c = 39,
  zero_negative_pressure = TRUE
)
```

### Validate processed data

``` r
gp <- validate_ankom(
  gp
)
#> ANKOM data validation passed.
#> Observations: 1752
#> Heads: 24
#> Treatments: 5
```

### Fit Gompertz model

``` r
gompertz_fit <- fit_gompertz(
  gp
)
#> ANKOM data validation passed.
#> Observations: 1752
```
